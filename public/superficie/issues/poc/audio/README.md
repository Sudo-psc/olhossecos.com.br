# Sons de passagem de página do POC

`paper-soft-1.wav`, `paper-soft-2.wav` e `paper-soft-3.wav` são efeitos originais,
gerados proceduralmente pelo script `scripts/generate-superficie-poc-assets.mjs`.

Não derivam de gravações, músicas ou bibliotecas de terceiros. Para permitir seu uso
e substituição no projeto, estes três arquivos são dedicados ao domínio público sob
CC0 1.0. O som fica desativado por padrão e toca em volume baixo apenas após ativação
explícita da pessoa leitora.
